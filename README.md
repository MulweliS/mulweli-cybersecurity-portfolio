# Mulweli Sinyegwe Cybersecurity Portfolio

Professional portfolio showcasing IT support experience, certifications, technical capabilities, and progression toward a SOC Analyst / Cybersecurity Analyst role.

## Run locally
1. Install Node.js.
2. Run `npm install`.
3. Run `npm run dev`.

## Deploy
Import this repository into Vercel. Vercel should detect Vite automatically. Build command: `npm run build`. Output directory: `dist`.
